# Weldall Client releases

Installers of the Weldall Client for SeibertGPT customers. Installation guide: https://gpt.seibert.ai/clients/weldall-client

These addresses always serve the newest version:

- macOS (Apple Silicon): https://github.com/seibert-external/weldall-client-releases/releases/latest/download/seibertgpt-mac-arm64.dmg
- Linux x64 (.deb): https://github.com/seibert-external/weldall-client-releases/releases/latest/download/seibertgpt-linux-x64.deb
- Linux x64 (.zip): https://github.com/seibert-external/weldall-client-releases/releases/latest/download/seibertgpt-linux-x64.zip

Each release carries a `SHA256SUMS`. The macOS app is signed and notarized by Seibert Group GmbH. The app is built on goose (Apache 2.0); the license ships inside the app.

This repository holds release files only, no source code.
